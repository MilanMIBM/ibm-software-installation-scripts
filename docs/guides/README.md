# Install guides

Short, step-by-step guides for running an install. Pick the one that matches where the install runs.

- [Installing from this machine](local-install.md): the default local run on one cluster, every product, every image source (entitled, private registry, air-gapped / local registry).
- [In-cluster install (one cluster)](in-cluster-install.md): move a CP4D install into a pod on the cluster (entitled images only), then watch, collect and tear down its slot.
- [Installing on three clusters in one run](multi-cluster-install.md): one command across several clusters, mixing in-cluster and local runs.

For every setting, see the main [README](../../README.md#installation-mode-variants-and-image-registry-options).
